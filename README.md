# DeepSeek Price Widget

[繁體中文（香港）](README.zh-HK.md) · [繁體中文（台灣）](README.zh-TW.md) · [简体中文](README.zh-CN.md) · [English](README.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-BR.md)

A floating Windows desktop widget showing DeepSeek API peak/off-peak periods and live prices, with multi-currency and multi-language support.

> Unofficial tool. Always refer to the official DeepSeek pricing page for final prices.

## Features

- Peak/off-peak detection based on Beijing time and Chinese public holidays, with countdown
- Automatic price fetching from the official `pricing.md`, with failure/staleness indicators and price-change history
- **16 currencies**: CNY, HKD, USD, EUR, JPY, GBP, AUD, CAD, CHF, SGD, KRW, THB, BRL, TWD, VND, RUB
  - FX providers tried in order: open.er-api.com → fawazahmed0 currency-api → frankfurter.app
- **11 languages** (plus follow-system), optional automatic currency per language
- Cost estimator (cache hit rate, input/output tokens) and service status (official RSS)
- System tray, global hotkey `Ctrl+Alt+D`, light/dark themes, position memory and edge snapping

## Requirements

- Windows 10/11 with built-in .NET Framework 4.8
- PowerShell 5.1 (the build uses the built-in `csc.exe`; no SDK required)

## Build

```powershell
powershell -ExecutionPolicy Bypass -File src\build-widget.ps1
```

This produces `DeepSeekPriceWidget.exe` in the project root. `assets\app.ico` is generated by the script.

## Usage

Double-click `DeepSeekPriceWidget.exe` or `啟動DeepSeek價格小工具.bat`.

Right-click for corners, appearance, language, currency, estimator, price history and shortcut help.
Shortcuts: `Ctrl+Alt+D` (show/hide), `Ctrl+E` (estimator), `Ctrl+R` (refresh prices), `Ctrl+H` (hide to tray), `Ctrl+Shift+Q` (exit).

## Project layout

```
assets/   XAML UI and icon (app.ico generated at build time)
data/     settings, holidays, currencies, FX providers, price history
lang/     language packs (en, zh-CN, zh-TW, ja, ko, ru, fr, de, es, it, pt-BR)
logs/     logs and test output (created at runtime; not tracked)
src/      C# source, manifest, build script
```

## Maintenance (mostly no rebuild needed)

| Item | File | How |
|---|---|---|
| Holidays | `data/holidays.json` | Edit, then right-click "Reload holidays" |
| Currencies | `data/currencies.json` | Add `code` / `symbol` / `name`; `languageDefaults` maps language → currency |
| FX providers | `data/fx-providers.json` | Array order is priority; `url` / `container` / `lowerKeys` |
| Languages | `lang/*.json` | Copy `en.json`, translate values and `_name`; restart to appear in the menu |
| UI | `assets/*.xaml` | Edit and restart |
| Logic | `src/*.cs` | Close the widget, then run the build script |

Missing `currencies.json` / `fx-providers.json` are generated with defaults on first run.

## Tests

```powershell
DeepSeekPriceWidget.exe --statustest # official status RSS

```

Results are written to `logs/`.
